# PokéRecomp Wild Encounters

A PokéRecomp mod that lets you choose which Pokémon appears in normal wild encounters while preserving the original encounter levels and encounter rates.

## Current version

**v0.4.0**

This version has been tested and confirmed working.

## Features

- Enable or disable Wild Encounters from the mod options.
- Choose which Pokémon should replace normal wild encounters.
- Original encounter levels are preserved.
- Original encounter rates are preserved.
- Disabling the mod restores normal vanilla encounter behavior.
- Pokémon selection can be changed from the mod options.

## Supported games

- Pokémon Red
- Pokémon Blue
- Pokémon Yellow
- Pokémon Gold
- Pokémon Silver
- Pokémon Crystal

## How it works

When Wild Encounters is enabled, the mod replaces the species used by normal wild encounters with the selected Pokémon.

The original encounter itself is otherwise preserved, including its level and encounter rate.

For example, if the game normally generates a level 4 Rattata and Bulbasaur is selected, the encounter becomes a level 4 Bulbasaur.

## Development

Wild Encounters is still being developed.

Future versions may improve the Pokémon selection interface and add separate Generation 1 and Generation 2 Pokémon lists where appropriate.

## Compatibility

Designed for PokéRecomp.

Wild Encounters only modifies normal wild encounters while the mod is enabled.
